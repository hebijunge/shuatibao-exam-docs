# 变电安规

## 考试概况

- **考试性质**：国家电网/南方电网及电力企业**内部安规考试**（安规普考/准入考试，非社会统考），依据国家标准《电力安全工作规程 发电厂和变电站电气部分》（GB 26860-2011）及《国家电网公司电力安全工作规程（变电部分）》（Q/GDW 1799.1）。
- **考试对象**：变电运维、检修、试验等涉及变电设备作业的生产人员；国网安规普考分专业管理人员、生产人员等类别，按变电运检/变电施工等二级专业组卷。
- **考试形式**：闭卷笔试或机考，题型为判断、单选、多选（部分含简答/综合分析题）。
- **题型与题量**：公开题库示例为单选 495 题、多选 187 题、判断 267 题、简答 26 题；另一版本约 949 题。具体题量与题型以本单位下发版本为准。[题库示例 ↗](https://www.shititong.cn/246250)
- **考试要求**：作业人员对本规程**每年考试一次**；间断电气工作连续 **3 个月以上**须重新学习并考试合格后方可恢复工作；新参加电气工作的人员、实习人员和临时参加劳动人员经安全知识教育后方可下现场，且不得单独工作。
- **基本条件**：经医师鉴定无妨碍工作的病症（体格检查每两年至少一次）；具备必要电气知识和业务技能并经考试合格；学会紧急救护法特别是触电急救。
- **合格线**：企业内部考试通常 **80 分及以上合格**（以各单位规定为准）。

## 官方政策与最新变化

- **国家标准现行状态**：GB 26860-2011《电力安全工作规程 发电厂和变电站电气部分》为**强制性现行国家标准**，2011-07-29 发布、2012-06-01 实施，由国家能源局归口；修订计划 **20230928-Q-624** 已进入"正在批准"阶段，换版后以新版为准。[全国标准信息公共服务平台 ↗](https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D7E0C7D3A7E05397BE0A0AB82A)
- **企业标准依据**：《国家电网公司电力安全工作规程（变电部分）》（Q/GDW 1799.1-2013）及国网后续修订版本；南方电网执行相应企业规程，条款数值以本单位现行文本为准。
- **上位法**：《安全生产法》2021 年修正（主席令第八十八号，2021-09-01 施行），强化全员安全生产责任制与双重预防机制。[中国政府网 ↗](https://www.gov.cn/xinwen/2021-06/10/content_5616885.htm)
- **题库更新**：《国家电网有限公司安全知识考试题库》（2023 年版，中国电力出版社，ISBN 9787519878610）按年度修订；市面"变电安规 2024"题库已按新版条款更新。[题库示例 ↗](https://www.shititong.cn/246250)
- **备考提示**：安全距离表、操作顺序、工作票适用范围等数字与流程条款是换版重点，复习时务必核对所考版本。
- 以官方最新通知为准。

## 报考条件

- **考试性质**：国家电网/南方电网等电力企业**内部安规考试**（非社会统考），面向本单位涉及变电设备作业的在职人员——变电运维、检修、试验、管理等岗位；外部人员无报考渠道。
- **上岗前提**：经医师鉴定无妨碍工作的病症（体检每两年至少一次）；具备必要电气知识和业务技能；学会紧急救护法特别是触电急救。
- **新员工**：新参加电气工作的人员、实习人员和临时参加劳动人员经安全知识教育后方可下现场，且不得单独工作。
- **复考情形**：因故间断电气工作连续 **3 个月以上**者，须重新学习规程并考试合格后才能恢复工作。
- 以所在单位最新规定为准。

## 报名与费用

- **报名方式**：由所在单位（部门）统一组织报名，按国网安委会年度安全知识考试工作方案（安规普考/准入考试）执行；专业分变电运检、变电施工等二级专业选择。
- **考试频次**：作业人员每年考试一次；部分单位另组织季度抽考、专项准入考试。
- **考试费用**：企业内部考试，一般不向个人收费。
- **考前准备**：单位统一发布题库/考试范围与考试安排（机考或闭卷笔试）。
- 以所在单位通知为准。

## 考试大纲与科目范围

### 《变电安规 通用部分》
1. 总则：适用范围、术语定义（高压/低压、运用中电气设备、设备双重名称）、作业人员条件、现场基本要求。
2. 保证安全的组织措施：工作票制度、工作许可制度、工作监护制度、工作间断/转移/终结制度。
3. 保证安全的技术措施：停电、验电、接地、悬挂标示牌和装设遮栏（围栏）。
4. 设备不停电时安全距离与工作中正常活动范围安全距离表。
5. 倒闸操作：操作票、监护复诵、操作顺序、防误闭锁、五大恶性误操作防范。
6. 高压设备巡视、SF6 配电装置、低压电气与二次回路工作。
7. 触电急救、电气火灾扑救、紧急救护法。

### 《变电运检 / 变电施工（二级专业）》
1. 变电站巡视与倒闸操作专项要求。
2. 设备检修、试验、继电保护与自动化装置作业。
3. 变电施工：施工用电、起重与高处作业、临边洞口防护。
4. 工作票"三种人"职责与资格管理。

### 题型范围
- 单选、多选、判断为必考；简答/综合分析题考查"两票办理+技术措施+事故处置"的完整流程。具体大纲与题量以本单位方案为准。

## 知识点体系

### 模块一：总则与术语
- **适用范围**：适用于运用中的发电、输电、变电（含特高压、高压直流）、配电及用户电气设备上及相关场所工作的所有人员，其他单位和相关人员参照执行。
- **电压等级定义**：**低压**指用于配电的交流系统中 **1000V 及以下**的电压等级；**高压**通常指超过低压的电压等级，特定情况下指电力系统中高风险等级。
- **运用中电气设备**：全部带有电压、一部分带有电压或一经操作即带有电压的电气设备——这是判断"是否需停电"的前提。
- **设备双重名称**：设备名称 + 编号，操作与工作票填写时必须同时使用。
- **作业人员条件**：医师鉴定无妨碍工作病症（体检每两年至少一次）、具备电气知识与技能并经考试合格、学会触电急救。

### 模块二：保证安全的组织措施
- **工作票制度**：第一种工作票用于高压设备全部停电、部分停电或需做安全措施的工作；第二种工作票用于大于安全距离的场所、带电设备外壳上的工作及不可能触及导电部分的工作；口头/电话命令用于简单、危险性小的作业。
- **五种人职责**：工作票签发人（确认必要性、安全性、人员资质）、工作负责人/监护人（组织、监护、交底）、工作许可人（审查安全措施、许可开工）、专责监护人（专职监护不得离岗）、工作班成员（遵守规程、服从监护）。
- **三种人不得兼任**：工作票签发人、工作负责人、工作许可人三者安全责任不得相互兼任（小规模作业中签发人可兼任负责人，以本单位规程为准）。
- **工作许可程序**：许可人审查安全措施 → 会同负责人到现场确认 → 双方办理许可手续；**禁止约时停送电**。
- **间断与终结**：间断后复工须重新检查安全措施；终结须双方验收、拆除接地线、清点人员工具后方可恢复送电。

### 模块三：保证安全的技术措施
- **停电作业五步**：停电 → 验电 → 接地 → 悬挂标示牌 → 装设遮栏（围栏），顺序不可颠倒，由运行人员或有权执行操作的人员完成。
- **验电**：使用相应电压等级且合格的验电器，验电前先在有电设备上试验确认良好，逐相验电，高压验电戴绝缘手套；无法直接验电时可间接验电（至少两个非同源指示同时变化）。
- **接地线**：应先接接地端、后接导体端，拆除顺序相反；装拆均使用绝缘棒并戴绝缘手套；成套接地线截面不小于 **25mm²**，严禁用缠绕方式接地。
- **标示牌**："禁止合闸，有人工作！"挂在一经合闸即可送电的开关把手；"在此工作""止步，高压危险""从此上下"等按位置对应悬挂。

### 模块四：安全距离与倒闸操作
- **设备不停电时安全距离**：10kV 及以下 **0.70m**、20/35kV **1.00m**、66/110kV **1.50m**、220kV **3.00m**、330kV 4.00m、500kV **5.00m**、750kV 7.20m、1000kV 8.70m；未列电压等级按高一挡执行。
- **工作中正常活动范围距离**：10kV 约 **0.35m**（具体数值以规程表为准），小于规定值必须停电，介于停电与不停电距离之间须设临时遮栏。
- **倒闸操作顺序**：停电拉闸按"断路器 → 负荷侧隔离开关 → 电源侧隔离开关"；送电合闸顺序相反。
- **监护复诵制**：监护人唱票、操作人复诵、逐项打勾；"一人操作、一人监护"，雷电时禁止倒闸操作，雨天室外操作使用带防雨罩的绝缘棒。
- **防五大恶性误操作**：误分误合断路器、带负荷拉合隔离开关、带电挂接地线、带接地线合闸、误入带电间隔。

### 模块五：特殊作业与急救
- **巡视**：单人巡视不得进行任何工作、不得移开或跨越遮栏；雷雨天巡视室外高压设备穿绝缘靴、不得靠近避雷针和避雷器。
- **SF6 配电装置室**：进入前先通风 **15 分钟**并检测含氧量，SF6 气体泄漏时按规程处置。
- **触电急救**：先脱离电源（拉闸/绝缘物挑开），再判断意识与呼吸，心肺复苏按压 **100–120 次/分**，送医途中不得停止施救。
- **电气火灾**：先断电，用干粉/二氧化碳灭火器或干砂，**严禁用水和泡沫**。

## 高频考点

### 组织措施（最高频章节）
1. （高频）**两票三制**：工作票、操作票；交接班制、巡回检查制、设备定期试验轮换制——安规第一高频考点。
2. （高频）第一种/第二种工作票适用范围：全部/部分停电或需做安全措施→第一种；大于安全距离的场所、带电设备外壳工作→第二种。
3. （高频）三种人职责与兼任禁令：工作票签发人、工作负责人（监护人）、工作许可人三者安全责任不得兼任；专责监护人不得兼做其他工作、不得离开现场。
4. （高频）工作许可程序：许可人审查安全措施→会同负责人到现场确认→双方办理许可手续；**禁止约时停送电**。
5. （高频）工作间断与终结：间断后复工须检查安全措施；终结须双方验收、拆除接地线、清点人员工具后方可恢复送电。
6. （中频）低压指交流 **1000V 及以下**，高压为超过低压的电压等级；运用中电气设备"一经操作即带电"也算。

### 技术措施
7. （高频）**停电作业五步顺序**：停电 → 验电 → 接地 → 挂牌 → 装设遮栏——顺序绝对不能乱。
8. （高频）**接地线**：先接接地端、后接导体端，拆除相反；严禁带地线合闸、严禁带电挂地线；装拆用绝缘棒并戴绝缘手套；成套接地线截面不小于 25mm²。
9. （高频）**验电**：用相应电压等级合格验电器；验电前先在有电设备上试验确认良好；逐相验电；高压验电戴绝缘手套。
10. （高频）标示牌对应："禁止合闸，有人工作！"挂在送电开关把手；"止步，高压危险"装在遮栏；"在此工作""从此上下"按位置对应。

### 安全距离（必背数字）
11. （高频）设备不停电时安全距离：10kV 及以下 **0.7m**、20/35kV **1.0m**、66/110kV **1.5m**、220kV **3.0m**、330kV 4.0m、500kV **5.0m**、750kV 7.2m、1000kV 8.7m。
12. （高频）检修距离：10kV 正常活动范围约 **0.35m**，小于规定值必须停电；介于停电与不停电距离之间需设临时遮栏。
13. （中频）未列电压等级按**高一挡**执行；13.8kV 执行 10kV 标准。

### 倒闸操作
14. （高频）**操作顺序**：停电拉闸"断路器 → 负荷侧隔离开关 → 电源侧隔离开关"；送电合闸顺序相反——顺序题必考。
15. （高频）监护复诵制：监护人唱票、操作人复诵、逐项打勾，"一人操作、一人监护"。
16. （高频）防五大恶性误操作：误分误合断路器、带负荷拉合隔离开关、带电挂接地线、带接地线合闸、误入带电间隔。
17. （中频）雨天室外操作使用带防雨罩绝缘棒；雷电时禁止倒闸操作。

### 巡视与其他
18. （中频）单人巡视不得进行任何工作、不得移开或跨越遮栏；雷雨天穿绝缘靴、不得靠近避雷针避雷器。
19. （中频）SF6 配电装置室进入前通风 **15 分钟**并检测含氧量。
20. （中频）触电急救：先脱离电源，心肺复苏按压 **100–120 次/分**，送医途中不停止施救。

## 记忆口诀与速记技巧

- **安全距离口诀**："10 零 7，35 一，110 一米五，220 走三米；330 四、500 五，750 七二 1000 八七。"
- **电压等级推导口诀**："330 以上除 100，约等于安全距离（米）。"
- **停电作业五步口诀**："先停电，后验电，挂上地线再围栏，最后挂牌标清楚"——"断、验、挂、围、标"五字经。
- **接地线口诀**："先接地端后导体，拆除顺序反着来；携带型地线 25 方，缠绕接地要不得。"
- **验电口诀**："验电先试有电设备，逐相验电戴手套；高压绝缘棒，不能直接摸。"
- **倒闸操作口诀**："停电先断断路器，再拉负荷侧刀闸，最后拉电源侧；送电顺序倒过来。"
- **五种人职责口诀**："签发管必要、负责管组织、许可管许可、专责只监护、班成员守规矩。"
- **触电急救口诀**："脱、诊、抢、持、送"——脱离电源、诊断意识呼吸、心肺复苏、持续施救、送医。
- **三宝口诀**：安全帽、安全带、接地线（电气检修）。
- **四不伤害口诀**："不伤己、不伤人、不被伤、护人不被伤。"
- **四不放过口诀**："原因不清、责任未究、教育未到、措施未立。"
- **三交三查口诀**："交任务、交技术、交安全；查衣着、查三宝、查精神。"
- **作业前四清楚口诀**："任务、危险点、程序、措施——四清楚；人员、措施、执行、监督——四到位。"
- **交接班口诀**："五清两交、四不交接"——看清讲清问清查清点清；交运行方式与注意事项、交设备缺陷与安全措施；操作未完成不交、记录不清不交、现场不清不交、事故处理未告一段落不交。

### 答题技巧
- 判断题"严禁、禁止、不得"类表述绝大多数是对的；出现"约时停送电""口头命令即可"多为错误项。
- 安全距离与操作顺序选择题优先选**最保守**答案（距离更大、步骤更全）。
- 实操类题按"步骤优先于动作"作答：停电五步、许可流程、终结流程背熟再做题。
- 数字考点（0.7/1.0/1.5/3.0/5.0m、0.35m、15 分钟、100–120 次/分）做卡片每天过一遍。
- 错题按"粗心/概念/记忆"三类归因，重做率目标 >90%；换版后第一时间重做数字与流程类题目。

## 成绩与证书

- **合格线**：企业内部考试通常 **80 分及以上合格**（以各单位规定为准）。
- **成绩规则**：单选、多选、判断按标准答案判分，简答/综合分析题按要点给分；不合格可补考。
- **不合格处理**：一般安排补考直至合格；安规考试未合格不得从事相应电气工作、不得担任工作票相关职务。
- **证书性质**：岗位任职资格依据（工作票签发人/负责人/许可人须在考试合格名单内），**不颁发对外资格证书、无公共查询平台**；合格名单由单位安全监察部门备案管理。
- **有效期**：按年度有效，每年至少考试一次；间断电气工作 3 个月以上须重新学习考试。
- **考试周期**：每年至少考试一次；官方题库按年度修订更新。
