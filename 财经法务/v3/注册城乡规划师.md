# 注册城乡规划师

## 资料信息

- **所属大类**：财经法务
- **文档名称**：注册城乡规划师
- **内容类型**：考试信息 / 知识点 / 备考资料
- **最近整理**：2026-11-27
- **使用提示**：报考政策、考试时间、费用和证书要求以官方最新通知为准。

## 考试概况
- **发证机关**：自然资源部、人力资源和社会保障部共同管理（依据《注册城乡规划师职业资格制度规定》《注册城乡规划师职业资格考试实施办法》，自然资规〔2024〕3号）；自然资源部人力资源开发中心负责大纲编写、命审题、阅卷，人社部人事考试中心负责考务。[报考须知 ↗](https://rsks.gd.gov.cn/kswj/bkwj/content/post_4730735.html)
- **考试科目（四科）**：
  1. 《城乡规划原理》（客观题，2.5小时）
  2. 《城乡规划相关知识》（客观题，2.5小时）
  3. 《城乡规划管理与法规》（客观题，2.5小时）
  4. 《城乡规划实务》（主观题，3小时）——唯一主观科目
- **考试安排**：每年第三季度举行；2026年度考试日期为9月12—13日，预计报名6月17日—7月6日，预计11月中旬公布成绩（以中国人事考试网年度计划为准）。[2026年度考试预告 ↗](http://mp.weixin.qq.com/s?__biz=MzIyODc4NTU2OA==&mid=2247497849&idx=2&sn=2f6c3e1f3c04000c16c8448f97bfbb8a)
- **合格标准**：实行相对固定合格标准——各科目合格标准为试卷满分的60%（四科满分均100分，即每科60分合格）。
- **成绩滚动管理**：考全科须在**连续4个考试年度**内通过全部科目；免试一科的3年滚动；免试两科的2年滚动。[报考简章 ↗](https://zrzyt.fj.gov.cn/zwgk/rsxx/202506/t20250612_6924380.htm)
- **报考条件（考全科，具备其一）**：城乡规划专业大专+国土空间规划业务工作满4年；城乡规划本科或建筑学学士（专业学位）+满3年；通过专业评估（认证）的城乡规划本科+满2年；城乡规划硕士或建筑学硕士（专业学位）+满1年；通过专业评估的城乡规划硕士或城市规划硕士（专业学位）+满1年；城乡规划博士（无年限要求）；其他专业相应年限增加1年。
- **免试规则**：符合硕士（专业评估认证/城市规划硕士）+1年或博士条件的，可免试《城乡规划原理》；持一级注册建筑师证书的可免试《原理》《相关知识》两科。
- **科目题型**：管理与法规——单选80道+多选20道，150分钟，满分100；实务——全部主观案例分析，一般6—7道大题，180分钟，满分100。

## 报考条件（考全科，具备其一）
1. 城乡规划专业大学专科学历，从事国土空间规划业务工作满4年；
2. 城乡规划专业大学本科学历或学位，或建筑学学士学位（专业学位），从事国土空间规划业务工作满3年；
3. 通过专业评估（认证）的城乡规划专业本科学历或学位，从事国土空间规划业务工作满2年；
4. 城乡规划专业硕士学位或建筑学硕士学位（专业学位），从事国土空间规划业务工作满1年；
5. 通过专业评估（认证）的城乡规划专业硕士学位或城市规划硕士学位（专业学位），从事国土空间规划业务工作满1年；
6. 城乡规划专业博士学位。
- **其他专业**：相应学历学位的从事国土空间规划业务工作年限增加1年。
- **免试**：符合第5、6项条件者可免试《城乡规划原理》；持一级注册建筑师证书者可免试《原理》《相关知识》两科。

## 考试大纲与科目范围
### 《城乡规划原理》
1. 城市与城市发展：城市化进程、城市性质与规模、城市职能与空间结构。
2. 国土空间规划体系：「五级三类」规划体系、总体规划—详细规划—专项规划的层级关系。
3. 国土空间总体规划编制：发展目标、空间格局（三区三线）、要素配置与用途管制。
4. 详细规划：控制性详细规划（用地性质、容积率、建筑密度、绿地率、建筑高度等控制指标）、修建性详细规划。
5. 城市设计、镇乡村规划、历史文化遗产保护规划原理。
### 《城乡规划相关知识》
1. 城市道路与交通：道路等级、路网形式、交通需求预测四阶段法。
2. 市政工程：给水、排水（分流制/合流制）、电力、燃气、通信、管线综合布置原则。
3. 建筑学基础：建筑分类、无障碍设计、消防间距、住宅与公共建筑设计常识。
4. 城市生态与环境、城市地理与经济、城市社会学、城市地理信息系统（GIS）常识。
5. 现行规范：《住宅项目规范》《民用建筑设计统一标准》《城市综合交通体系规划标准》等。
### 《城乡规划管理与法规》
1. 核心法规：《城乡规划法》《土地管理法》及配套法规；国土空间规划相关法规。
2. 专项法规：历史文化名城名镇名村保护条例、文物保护法、风景名胜区条例、生态保护红线相关法规。
3. 行政法基础：行政许可、行政处罚、行政复议、行政诉讼、行政强制。
4. 规划管理流程：规划编制审批修改监督检查；规划许可（选址意见书、建设用地规划许可、建设工程规划许可、乡村建设规划许可）。
5. 政策文件：耕地保护、三区三线管控、国家空间治理最新文件（时效性强、每年必考新政策）。
### 《城乡规划实务》
1. 国土空间总体规划案例评析；控制性详细规划方案纠错；修建性详细规划修改分析。
2. 村庄规划、历史街区保护规划案例。
3. 道路交通、市政管线专项规划问题识别。
4. 规划行政许可、违法用地与违法建筑处置。
5. 规划编制程序、审批流程、公众参与、规划修改合规性判断。
### 大纲依据
- 沿用《全国注册城市规划师执业资格考试大纲》（2014版）及自然资空间规划函〔2020〕190号增补内容；以自然资源部最新发布为准。[考试通知 ↗](https://hrss.qingdao.gov.cn/ztzl_47/rsks_47/tzgg_47/202506/t20250616_9680768.shtml)

## 知识点体系
### 模块一：城乡规划原理基础
- **城市化**：城市化水平衡量指标（城镇人口比重）、城市化阶段（初期、加速、稳定）、郊区城市化与逆城市化现象；我国新型城镇化以人为本、城乡融合的发展导向。
- **城市性质与规模**：城市性质是城市在区域中的主要职能与定位；城市规模按人口规模划分，用地规模与人口规模对应；城市职能分类（政治、经济、文化等）。
- **五级三类国土空间规划体系**：五级为国家、省、市、县、乡镇；三类为总体规划、详细规划、专项规划。总体规划是战略性纲领，详细规划是实施性安排，专项规划是特定领域安排——层级关系与衔接是高频考点。
- **三区三线**：生态空间、农业空间、城镇空间三种国土空间；生态保护红线、永久基本农田、城镇开发边界三条控制线。三线不得随意调整，调整须按法定程序。

### 模块二：详细规划与城市设计
- **控制性详细规划**：确定用地性质、用地面积、容积率、建筑密度、建筑高度、绿地率、建筑退界、配套设施等控制指标；分为规定性指标（必须执行）与指导性指标（引导性）。
- **容积率**：总建筑面积与用地面积的比值；容积率调整须经过论证、公示、听证等程序，且不得突破上位规划确定的总量。
- **修建性详细规划**：在控规基础上细化空间布局、道路系统、绿地系统、建筑形体与工程管线，是建设的直接依据。
- **城市设计**：关注城市空间形态、景观风貌、公共空间与建筑群体关系；历史街区保护强调肌理延续与风貌协调。

### 模块三：城乡规划相关知识
- **城市道路与交通**：城市道路分级（快速路、主干路、次干路、支路）；路网形式（方格网、放射状、环形放射、自由式）的优缺点；交通需求预测四阶段法——生成、分布、方式划分、分配。
- **市政工程规划**：给水（水源—水厂—管网）、排水（分流制与合流制的适用条件）、电力（变电站布局与高压走廊）、燃气、通信、热力；管线综合避让原则——小管让大管、压力管让重力管、分支管让主干管、临时让永久。
- **建筑学常识**：建筑分类（民用与工业）、耐火等级、防火间距、无障碍设计要点；《住宅项目规范》《民用建筑设计统一标准》是现行规范依据。
- **城市生态与经济**：生态适宜性分析、环境容量、城市热岛效应；城市经济学中的地租理论、产业集聚；GIS在规划中的应用（叠图分析、缓冲区分析）。

### 模块四：城乡规划管理与法规
- **《城乡规划法》核心**：先规划后建设；规划区内建设须取得规划许可；违法建设的责令停止、限期拆除、罚款等处罚措施；规划修改的法定程序。
- **规划许可「一书三证」**：选址意见书（划拨用地项目）、建设用地规划许可证、建设工程规划许可证、乡村建设规划许可证——适用情形与核发主体是必考点。
- **行政法基础**：行政许可的设定与实施机关、行政处罚的种类与听证条件、行政复议的申请期限（60日）与诉讼期限（6个月）、行政强制措施与强制执行的区别。
- **历史文化保护**：历史文化名城、名镇、名村的保护规划编制；核心保护范围内不得进行新建、扩建（必要设施除外）；建设活动须经审批。
- **时效政策**：耕地保护制度、三区三线管控规则、国土空间规划体系建设最新文件——每年必考新政策，须关注自然资源部发布。

### 模块五：城乡规划实务
- **总体规划评析**：从目标定位、空间结构、用地布局、交通体系、生态保护等方面评价方案优缺点，指出违反上位规划或底线管控的问题。
- **控规方案纠错**：检查用地性质是否符合上位规划、指标是否超标（容积率、密度、高度、绿地率）、配套设施是否缺失、道路系统是否完整、是否符合三区三线管控。
- **道路与市政专项规划**：路网结构是否合理、道路等级衔接、停车场布局、管线综合冲突（如管线交叉标高冲突）。
- **违法建设处置**：区分违法用地与违法建筑，判断是否需要责令停止、限期拆除或补办手续；处罚主体与程序要准确。
- **答题规范**：按「错误点+规范表述」双段式作答，逐条列出采分点；使用法定术语（如「违反《城乡规划法》第X条」「不符合控规规定性指标」）。

### 答题技巧
- **备考顺序**：「先原理搭框架，再法规守底线，后知识补工程，最后实务综合突破」——实务必须放在三科客观题之后学习。
- **法规技巧**：法条为王，大量原题变形，新出台国土空间政策必考；易混淆法条做对比表；多选题失分率高，宁缺勿滥。
- **实务技巧**：不考背诵考「读图找错+规范话术」——练真题图纸题；答题写「错误点+规范表述」双段式，按采分点给分；「少数服从多数」不是规划决策原则（经典错误选项）。
- **客观题技巧**：题干出现「应当」「必须」「一律」时核对法条原文；时态与主体（谁审批、谁核发）是常见陷阱。
