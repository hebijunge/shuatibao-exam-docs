# 刷题宝 · 考试资料库

目标：用户看到某个题库或文档后，能直接理解这个技能/考试，并从零开始学习、练习和自测。

- 覆盖刷题宝 App 当前 379 套题库 / 18 个行业分组 / 138 个考试文档
- App 内「知识点」Tab 会按当前所选题库自动加载对应文档
- 索引：`index3.json`（明确名称/别名映射；不再使用题库 ID 或大类兜底，避免错配）

## 文档结构（每考试一个 md）

1. 资料信息：元数据表、适用等级、考试形式、版本
2. 30秒速览：是什么、适合谁、考什么、怎么考、难点、学习成果
3. 技能学习地图：能力模块、学习成果、自测方式
4. 学习与培训计划：按考试类型制定 6 周计划、冲刺计划、每日模板
5. 教材正文与考前培训：学习目标、模块讲义、课堂练习、参考答案、实训练习（真实教学内容，不放外链）
6. 考试概况与官方政策
7. 报考条件、报名与费用、考试大纲
8. 知识点体系、知识点精讲、高频考点
9. 参考资料与出处、官方资料核验（链接只放在这里）
10. 成绩与证书、学习清单

## 版式规范

- 只使用标准 Markdown：标题、表格、列表、引用块、分隔线。
- 不使用 HTML、CSS、脚本或依赖特定渲染器的语法。
- 元数据使用表格；政策、教材资料、关键数字优先使用表格。
- 重要提示使用引用块，例如 `> **使用提示**：...`。
- 培训正文不放外链；外部链接只放在“教材与备考资料”和“官方资料核验清单”。
- 内容按“认识 → 学习 → 练习 → 自测 → 应用”组织，避免只堆链接和考点。
