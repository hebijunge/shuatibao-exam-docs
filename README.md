# 刷题宝 · 考试资料库

职业资格考试知识点/高频考点/记忆口诀/教材目录/报考条件/报名费用/证书查询全流程资料。

- 覆盖刷题宝 App 全部 1719 套题库 / 18 个行业分组 / 135 个考试文档
- App 内「知识点」Tab 会按当前所选题库自动加载对应文档
- 索引：`index.json`（题库编号 → 文档路径映射，`group_fallback` 兜底）
