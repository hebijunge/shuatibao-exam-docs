## 教材正文与考前培训

### 第一章 专职安全管理人员的职责与权限

专职安全生产管理人员包括企业安全分管负责人、安全总监、安全机构人员和项目专职安全员等。其职责是组织或参与风险辨识、检查、教育培训、隐患治理、应急和事故报告，监督各项安全制度执行。

C 证人员应熟悉现场，但不能替代工艺、设备和作业班组的专业判断。发现不懂的技术参数时，应暂停相关作业并请专业人员复核，不能凭猜测放行。对违章指挥、强令冒险作业和直接危及人身安全的紧急情况，应依法制止并组织撤离。

检查权、建议权和报告权必须与企业制度衔接。对重复违章和重大隐患，要报告项目负责人和单位负责人，必要时向主管部门报告，不能只在记录本上写“已提醒”。

**例 1：班组要求安全员在未验收的脚手架上签字，安全员担心影响关系只口头提醒。** 应明确拒绝签字，设置隔离和停工，报告并组织验收，不能以提醒代替制止。

**易错辨析**：专职人员不是“资料员”；检查不能替代专业设计；口头提醒不等于完成处置；报告不能等到事故发生。

**章节练习**：列出十项可现场直接制止的危险行为，并说明报告路径。

### 第二章 检查方法、证据与闭环

检查应按风险确定频次和重点，结合日常巡查、专项检查、季节性检查和作业前检查。使用检查表能保证覆盖，但现场观察、仪器检测和人员访谈同样重要，不能只打勾。

证据必须能支持结论。设备问题要记录编号、状态和检测结果；作业问题要记录时间、人员、作业内容和违反条款；管理问题要核对制度、培训、审批和签到是否真实。

隐患治理按“发现—登记—评估—控制—整改—复查—销号”运行。重大隐患立即停工报告，一般隐患明确责任和期限。复查应验证措施有效，不能只看照片或整改人的自我声明。

**例 2：同一区域连续三次发现灭火器被遮挡，每次拍照后都销号。** 说明治标不治本。应分析定置、通道管理、班前检查和奖惩，采取防复发措施并持续验证。

**易错辨析**：检查表不是现场本身；照片不能证明所有功能；签字不能替代验证；销号不能由整改人单独决定。

**章节练习**：用模拟检查表完成一次“码头吊装区”检查，写出五项问题和复查证据。

### 第三章 水运工程现场风险辨识

水运现场风险包括船舶锚泊和定位、通航干扰、潮汐水流、风浪、打桩、吊装、疏浚、临水临边、夜间和恶劣天气。安全员应能把自然条件转化为具体停工信号，而不是只说“注意天气”。

施工船舶和设备应核验证书、检验、适用工况、安全装置和维护状态。起重设备要关注限位、制动、力矩保护、钢丝绳和吊具，打桩船和起重船还要关注定位、稳性和作业窗口。

专项方案实施时，安全员应监督关键参数、人员、隔离、监测和应急是否与方案一致。现场地质、荷载或设备变化时，应立即报告并停止相关作业，不能自行修改参数。

**例 3：现场风速接近预案停工阈值，安全员以“还没到”为由继续。** 应结合阵风、船舶运动、吊装对象和通信条件提前评估，必要时提前停工，不能等待事故信号。

**易错辨析**：设备有证不等于工况适合；天气阈值不是可突破的目标；方案审批不等于现场执行；安全员不能自行决定技术变更。

**章节练习**：为模拟水上吊装建立风险清单，每项写明监测指标、停工条件和报告对象。

### 第四章 通用作业安全监督

高处作业要检查作业许可、脚手架、临边洞口、安全带和防坠措施。安全带应高挂低用并挂在可靠锚点，不能只检查是否携带。临时用电应检查配电、保护、接地、线路和漏电保护，严禁私拉乱接。

动火作业要审批、清理可燃物、隔离、检测和监护。受限空间要办理许可、隔离、通风、检测和全程监护，不能凭“闻不到味”进入。水上作业要检查救生衣、警戒、通信、船舶和救援，不能把救生衣当作唯一措施。

特种作业人员应持有效证书，证书类别与作业匹配。对承包商和临时人员应同等管理，不能因其不属本单位而降低要求。

**例 4：电焊工证书有效，但现场动火票未审批且下方有可燃物。** 仍应停止作业。持证不能替代作业许可和现场条件，必须清理、隔离、审批并监护。

**易错辨析**：证书不能替代许可；救生衣不能替代警戒和救援；闻不到味不等于受限空间安全；私拉临时电线不能因“只用一天”而接受。

**章节练习**：分别模拟高处、动火、受限空间和临水作业，列出否决条件和验证方法。

### 第五章 重大隐患、应急与事故报告

按 2025 年《公路水运工程生产安全重大事故隐患判定标准》，无有效安管证书、危大工程方案未编制审核审查、船舶或设备不符合要求等可构成重大隐患。安全员应熟悉判定条款，及时提出停工报告并跟踪治理。

事故发生后，应先确保自身安全，报警、疏散、警戒并组织力所能及的救援，及时报告项目负责人和单位。报告应真实、完整，不能因等级未确定而等待，也不能为了降低影响而隐瞒。

应急演练要检查通信、撤离路线、物资、救援和指挥是否有效。安全员应参与预案修订和培训，把事故案例转化为检查项，而不是只参加签名。

**例 5：事故现场有人受伤，安全员未佩戴防护就进入有毒区域拖人。** 不能盲目施救造成连续伤亡。应先报警、隔离、评估并佩戴适当防护，使用正确救援方法。

**易错辨析**：勇敢不等于无防护；报告不能等调查；应急物资存在不等于可用；演练签名不等于会应急。

**章节练习**：模拟“船舱有限空间人员昏迷”，编写安全警戒、检测、救援请求和医疗交接流程。

### 第六章 C 类案例题与检查实务

C 类案例常提供照片或场景，要求找出隐患、违反条款、立即措施和复查证据。答题可按“危险源—违规事实—后果—停工/整改—验证”组织，不能只写“立即整改”。

对技术题要准确使用术语：船舶检验、吊装、高处、临时用电、动火、受限空间和应急预案等。对管理题要落实主体、期限和记录。对紧急情况要把人员撤离和报告放在第一位。

日常工作中应建立个人检查路线和风险台账，利用班前会、移动终端和照片提高覆盖，但必须防止系统“两层皮”：线上全打勾、线下仍违章。对高频问题要做趋势分析并推动制度整改。

**例 6：案例中专项方案审批齐全，但现场剪刀撑间距与方案不符。** 应判定为现场未按方案施工，立即停工，恢复或履行变更，复检后才能继续。

**易错辨析**：资料齐全不等于现场合规；技术判断不能凭印象；整改必须验证；高频问题要分析系统原因。

**章节练习**：完成十道图片找错题，每题写出隐患、条款、立即措施和复查证据。

### 自测题与参考答案

1. **判断**：专职安全员只需记录隐患，不必制止紧急危险。**答：错误，应及时制止、组织撤离并报告。**
2. **选择**：动火票未审批但焊工持证，能否作业？**答：不能。**
3. **简答**：隐患闭环包括哪些环节？**答：发现、登记、评估、控制、整改、复查、销号。**
4. **判断**：受限空间闻不到味就可以进入。**答：错误，应审批、隔离、通风、检测和监护。**
5. **案例**：专项方案与现场不符，如何处理？**答：停工，恢复合规或履行变更，复检后复工。**

- **最新变化三：成绩衔接**：成绩合格后 **1 年内**申请考核，逾期须满足继续教育学时要求（2号令第八条）。
- **组织分工**：交通运输部制定大纲，省级交通运输主管部门组织实施；每年第一季度公布年度考试计划，考前30日公告考务内容。
- 各省报名批次、费用与考务以省级交通运输主管部门当期公告为准，详见[大纲PDF全文 ↗](https://ncx.nc.gov.cn/ncxrmzf/jtys/202407/41a42380464e4c25aeb3f9c50ca0b685/files/4e863b41d738430e9ee8512b560936b1.pdf)。

## 考试大纲与科目范围

依据交办安监函〔2024〕937号《安全生产考试大纲》，本文件为**水运工程领域 C 类（专职安全生产管理人员）**。C 类技术比重为三类岗位中最高。

### 《综合知识和管理能力》（约8%）
1. 综合知识：安全基本概念、事故致因分析、五化管理要求。
2. 管理能力：风险辨识、隐患治理、事故报告与应急处置。

### 《法律法规、部门规章及标准规范》（约25%）
1. 现场安全监督管理依据、作业人员权利与义务。
2. 特种作业管理、现场违规行为查处与法律责任。

### 《安全生产管理》（约25%）
1. 安全生产管理职责与制度、隐患排查治理程序与方法。
2. 安全检查方法与程序、应急管理。

### 《水运工程安全生产技术》（约42%，C证最大模块）
1. 施工安全技术准备、施工现场安全管理、个体安全防护。
2. 施工机械设备、通用作业（高处、水上、动火、临时用电等）。
3. 单位工程（码头、航道、疏浚、防波堤等）、特殊季节与特殊环境施工（高温、能见度不良、台风汛期等）。

### 考试要求（大纲原文）
- 计算机或纸质试卷闭卷，**90 分钟**，满分 100 分，**70 分及以上合格**；题型为单选、多选、判断、案例题；部基础题库 ≥85%。
- 组卷比例（C 类）：综合 8% + 法规 25% + 管理 25% + 水运安全技术 **42%**。

## 知识点体系

### 模块一：综合知识和管理能力（约8%）
- **安全基本概念**：安全生产方针、本质安全、风险与隐患的定义和区别；C 证考法偏"现场能不能识别"，常给出作业场景让考生判断属于哪类风险。
- **事故致因分析**：海因里希因果连锁、能量意外释放、轨迹交叉论；专职安全员须能从人的不安全行为、物的危险状态、管理缺陷三方面找出直接原因和间接原因。
- **五化管理要求**：安全管理规范化、现场管理网格化、风险管控动态化、事故隐患清单化、工程防护标准化——隐患清单化是 C 证日常工作的直接依据。
- **履职能力要点**：危险源辨识、隐患排查、现场监督检查、事故报告与初期处置、教育培训，C 证考的是"会不会查、会不会改、会不会报"。

### 模块二：法律法规、部门规章及标准规范（约25%）
- **现场安全监督依据**：《安全生产法》《建设工程安全生产管理条例》《生产安全事故报告和调查处理条例》及水运工程安全相关法规标准，明确专职安全员的检查权和报告权。
- **作业人员权利**：知情权（了解作业场所危险因素）、建议权、批评检举控告权、拒绝违章指挥和强令冒险作业权、紧急避险权；C 证常考"哪项权利被侵犯"的场景判断题。
- **作业人员义务**：遵守规章制度和操作规程、正确佩戴和使用劳动防护用品、接受教育培训、发现隐患立即报告。
- **特种作业管理**：电工、焊工、起重司机、信号司索工等须经专门培训并取得特种作业操作证，按规定复审，无证上岗属重大隐患。
- **违规行为查处**：对违章指挥、违章作业、违反劳动纪律"三违"行为的识别、制止与报告程序；专职安全员有权制止违章，但不得越权作出行政处罚。

### 模块三：安全生产管理（约25%）
- **隐患排查治理**：日常巡查、专项检查、季节性检查相结合；隐患登记→整改→复查→销号闭环；重大隐患须立即停止作业、撤出人员并上报。
- **安全检查方法**：常规检查表法、仪器检查法、安全检查表分析（SCL）、预先危险性分析（PHA）等；检查须有记录、有签字、有整改通知单。
- **应急管理**：项目应急预案三级体系、应急物资与器材检查、演练组织与评估、事故先期处置（警戒、疏散、报警、急救）。
- **事故报告**：现场人员立即报告，单位负责人 1 小时内上报；报告内容包括时间地点、简要经过、伤亡人数、已采取措施。
- **教育培训**：新进场工人三级教育（公司/项目/班组）、特种作业持证、班前安全交底、转岗复工教育，专职安全员负责组织与记录归档。

### 模块四：水运工程安全生产技术（约42%，最大模块）
- **施工安全技术准备**：施工组织设计中的安全技术措施、临时用电方案、危大工程专项方案；方案须审批后实施，作业前须书面交底。
- **施工现场安全管理**：临时设施选址与布置、材料堆放与标识、危险区域围挡与警示、临边洞口防护、消防器材配置；水运工地还需考虑潮位、船舶进出港与陆水交叉作业。
- **个体安全防护**：安全帽、安全带、救生衣、防滑鞋、防护手套、护目镜、防毒面具；**水上作业必须全程穿戴救生衣**。
- **施工机械设备**：起重机械力矩限制器、高度限位器、制动器等安全装置齐全有效；打桩船、起重船、挖掘机、装载机等须定机定人、专人指挥。
- **通用作业——高处作业**：坠落高度基准面 **2 米及以上**为高处作业，分级防护；安全带高挂低用，防护栏杆高度、安全网设置须符合标准。
- **通用作业——临时用电**：必须采用 TN-S 接零保护系统；三级配电、两级保护；开关箱执行"一机一闸一漏一箱"；漏保额定动作电流一般不大于 30mA、动作时间不大于 0.1s，潮湿场所不大于 15mA。
- **通用作业——动火与水上作业**：动火作业须审批、清理周边可燃物、专人监护、配备灭火器材；水上作业须设警戒船、恶劣天气停止作业。
- **单位工程专业工程**：码头、航道疏浚、防波堤、船闸等施工特点；临水作业防护、水下施工安全、船舶避让与锚泊。
- **特殊季节与特殊环境**：高温防暑降温、能见度不良（雾天）作业管制、台风汛期停工避险与撤离路线、夜间施工照明与警戒。

### 答题技巧
- 多选题错选、漏选整题零分；技术参数多，按"用电、高处、水上、机械、特殊季节"分块整理数字对照表。
- 事故场景题先判"属于哪类风险/隐患"，再写"违反哪条标准"，最后写"正确做法"。

## 成绩与证书

- **成绩**：机考现场提交即出分（70分及以上合格）
- **证书**：考核合格申领安管人员安全生产考核合格证书（C类）
- **专职在岗要求**：C证人员须专职从事安全管理，不得同时在其他单位任职
- **证书领域绑定**：分公路/水运领域，跨领域须增考
- **有效期与延续**：以交通运输部2024年2号令及各省规定为准；成绩合格后应在1年内申请考核
