# 放射工作人员培训（核技术利用辐射安全与防护考核）

## 考试概况

放射工作人员上岗培训对应的考核为**核技术利用辐射安全与防护考核**，由生态环境部统一组织。自2020年1月1日起，各级生态环境部门不再评估推荐培训机构，新从事辐射活动的人员及原培训合格证到期人员，须通过"国家核技术利用辐射安全与防护培训平台"报名参加考核。考核科目共**十一类**：医用X射线诊断与介入放射学、放射治疗、核医学、核子仪、放射性测井、X射线探伤、γ（伽马）射线探伤、电子加速器辐照、γ辐照、辐射安全管理、科研生产及其他。考核为闭卷机考，时长45分钟，公共科目与专业科目合卷；考核合格者取得《核技术利用辐射安全与防护考核成绩报告单》，全国有效。本组文档覆盖的题库涉及核医学、放射治疗、伽马射线探伤、辐射安全管理、伽马辐照、放射性测井、核子仪、医用X射线诊断与介入放射学、X射线探伤、工业辐照电子加速器理论等科目（"科研、生产及其他"科目单列一文）。

## 报考条件

- 年满16周岁，具备完全民事行为能力；
- 从事或准备从事核技术利用辐射安全相关工作；
- 无学历、专业、户籍限制，按个人辐射工作类别选择对应考核科目报名；
- 仅从事Ⅲ类射线装置销售、使用活动的人员，可免于集中考核，由所在单位按生态环境部参考试题库自行组织考核。

## 报名与费用

- **报名入口**：微信小程序"辐射安全培训"（公众号二维码见培训平台首页），或国家核技术利用辐射安全与防护培训平台——**fushe.mee.gov.cn**。
- **报名规则**：每位考生**一年最多可获得三次考核报名机会**；允许通过小程序为他人报名；报名需准备有效身份证件和免冠证件照（电子版）；报名后经考核机构审核通过方为成功。
- **准考证**：开考前一周在报名平台下载打印，凭准考证+有效身份证件原件（身份证、临时身份证、护照、港澳台居民居住证等）入场；考前15分钟进场，开考15分钟后不得入场，开考25分钟内不得交卷。
- **考核计划**：生态环境部门通过培训平台定期发布考核计划（各省集中考核安排以平台公告为准）。
- **费用**：培训平台在线学习**免费**；多数省份集中考核**免收考核费用**（如陕西明确免收），个别地区或收取考务成本费，以当地公告为准。
- **报考限制**：每次考试只能报考一个专业科目（可分次报考多个类别）。

## 成绩与证书

- **查分入口**：考核结束**5个工作日后**，登录微信报名小程序或培训平台（fushe.mee.gov.cn）查看考核结果。
- **证书**：考核合格者取得电子版《核技术利用辐射安全与防护考核成绩报告单》（经平台下载）；自行考核合格人员由单位颁发加盖公章的考核合格证明。
- **有效期**：集中考核和自行考核结果**有效期均为5年**；到期前应通过再次考核方可继续从事辐射活动。
- **全国有效**：考核成绩全国通用，跨省上岗无需重考（有效期内）。
- **配套义务**：放射工作人员还需按《放射性同位素与射线装置安全和防护条例》进行个人剂量监测、职业健康检查，单位建立培训考核档案。

## 知识点体系

1. **公共科目：电离辐射法律法规**：
   - 《放射性同位素与射线装置安全和防护条例》（国务院令第449号）、《放射性同位素与射线装置安全许可管理办法》、《放射工作人员职业健康管理办法》（卫计委令第55号）。
   - 许可证分类管理：生产、销售、使用放射性同位素与射线装置须取得辐射安全许可证；I类、II类、III类射线装置与放射源（I～V类）的分类管理要求。
   - 放射工作人员：年满16周岁持证上岗、个人剂量限值（职业人员连续5年年均有效剂量不超过20mSv，任何一年不超过50mSv）、个人剂量监测与职业健康监护。
2. **公共科目：电离辐射安全与防护基础**：
   - 辐射物理基础：α、β、γ、X射线及中子的性质与穿透力；半衰期、放射性活度（Bq）与剂量单位（Gy、Sv）。
   - 外照射防护三原则：**时间、距离、屏蔽**；内照射防护（防止吸入、食入）。
   - 辐射生物效应：确定性效应（有阈值）与随机性效应（无阈值、概率性）；孕早期胚胎敏感。
   - 辐射监测：个人剂量计（佩戴于左胸/躯干）、工作场所监测、表面污染监测。
3. **专业科目（按工作类别分）**：
   - **医用X射线诊断与介入放射学**：X射线机工作原理、诊断参考水平、受检者防护（正当化+最优化、屏蔽防护用品）、介入手术中术者防护。
   - **放射治疗**：钴-60治疗机、医用电子直线加速器、近距离后装治疗；机房联锁、剂量验证、治疗区患者防护。
   - **核医学**：放射性药物（99mTc、131I、18F等）使用、注射后患者管理、放射性废物处理、131I治疗病房管理。
   - **核子仪**：料位计、测厚仪等含源仪表的使用、换源操作防护。
   - **放射性测井**：油气田测井用密封源（137Cs、241Am-Be中子源）操作、装卸源规程。
   - **X射线探伤 / γ射线探伤**：移动式探伤作业分区控制（控制区、监督区）、联锁与警示、探伤室屏蔽要求。
   - **电子加速器辐照 / γ辐照**：辐照装置安全联锁、出入口控制、货物进出辐射监测。
   - **辐射安全管理**：单位辐射安全与防护管理（规章制度、档案、年度评估）、同位素与射线装置销售管理、辐射安全监管职责。
4. **事故应急**：放射源丢失/失控报告程序、人员受照应急处理、"宁可十防九空"的应急演练要求。

## 高频考点（按模块，含易错点）

1. **【高频】剂量限值**：职业照射——连续5年平均不超过20mSv/年，任何单一年份不超过50mSv；公众——每年1mSv（特殊情况下连续5年平均不超过1mSv/年）。易错点：职业限值不是"每年恰好20mSv"而是5年平均。
2. **【高频】外照射防护三原则**：时间（缩短受照时间）、距离（增大距离，平方反比定律——距离加倍剂量率降为1/4）、屏蔽（铅、混凝土等）。易错点：α粒子外照射危害小（穿透弱）但内照射危害大。
3. **【高频】射线性质与屏蔽**：α用一张纸即可挡住；β用铝/有机玻璃（高Z材料产生轫致辐射，不宜直接用厚铅）；γ/X射线用高密度材料（铅、混凝土）减弱。经典题：屏蔽β射线先用低Z材料如有机玻璃。
4. **【高频】放射源分类**：按活度分I～V类，I类为极高危险源（如辐照装置源），V类为极低危险源；丢失I类源属重大事件须立即报告。
5. **【高频】许可证要求**：生产、销售、使用放射性同位素和I类、II类射线装置的单位须取得省级生态环境部门颁发的辐射安全许可证（III类射线装置向市级申请的情形按规定执行）；许可证有效期5年。
6. **【高频】移动探伤作业分区**：控制区边界剂量率15μSv/h、监督区边界2.5μSv/h左右（以现行标准为准）；设置警戒、电离辐射标志与声光报警。
7. **【高频】受检者防护**：X射线诊断遵循正当化（避免不必要检查）与最优化（ALARA原则）；对非检查部位用铅橡皮屏蔽；儿童检查调低参数。易错点："检查剂量越大越清楚"错误——过度增加剂量只增加风险。
8. **【高频】个人剂量监测**：放射工作人员须佩戴个人剂量计（一般置于左胸前），3个月一周期监测；外照射个人剂量档案终身保存。
9. **【高频】核医学患者管理**：131I治疗患者住院期间限排泄物收集处理，出院标准按体内残留活度；对孕妇、儿童避免密切接触。易错点：注射放射性药物的患者的唾液、尿液均含放射性。
10. **【高频】半衰期计算**：经n个半衰期后活度变为(1/2)^n；混合衰变题用"有效半衰期"概念（物理+生物）。
11. **【中频】辐射监测仪器**：个人剂量报警仪、表面污染仪（α表面污染仪与γ剂量率仪区分）、热释光剂量计（TLD）原理。
12. **【中频】职业健康管理**：放射工作人员上岗前、在岗期间（一般1～2年一次）和离岗时职业健康检查；怀孕期间岗位保护（不安排可能导致胚胎受照的工作）。
13. **【中频】辐射事故分级**：特别重大（I级）、重大（II级）、较大（III级）、一般（IV级）四级；事故报告时限要求（2小时内报告属地生态环境部门）。
14. **【中频】联锁与安全装置**：辐照室/加速器机房多重联锁（门机联锁、红外防滞留、急停按钮、警示灯）；严禁旁路联锁运行。
15. **【中频】废物管理**：放射性废物按半衰期分类——短半衰期废物衰变贮存（一般10个半衰期）后可作一般废物处理；废放射源交有资质单位收贮，严禁自行处置。

## 记忆口诀与答题技巧

- 外照射防护："**时间短、距离远、屏蔽好**"。
- 距离衰减："**距离翻一倍，剂量率减为四分之一**"（平方反比）。
- 剂量限值："**职业五年均二十，单年不超五十毫；公众一年一毫希**"。
- 屏蔽选材："**挡α一张纸，挡β用铝塑，挡γ铅混凝土**"。
- 答题技巧：
  1. 本类考核以法规数值与防护原则为绝对主干：先把"三限值、三分区、五类源、两级许可"背牢，再刷专业科目题。
  2. 判断题中"剂量越高图像越好""联锁可以临时短接""废源自行深埋"等表述一律为错。
  3. 计算题（半衰期、平方反比）先写公式再代入，注意单位换算（1Sv=1000mSv）。
  4. 考试45分钟题量不小，公共科目部分先稳拿分，专业科目不确定题先标记后回看；45分钟考试严禁超时，25分钟后才可交卷离场。
  5. 备考核心资源是培训平台免费在线课程与参考试题库——**平台练习题与真题重合度高，务必先刷平台题库**。
